**Knownest** 是一款本地优先的 AI 知识管理桌面应用：Markdown 知识库整理、编辑、关联、以题复习一站式完成，内置自主 AI Agent 直接操作你的知识库。数据全在本机 SQLite 与 Git，开源 MIT。

- 官网：https://knownest.io
- 隐私 / 退款 / 联系：https://knownest.io/policies.html

## 下载

### 🪟 Windows

- 系统要求：Windows 10 / 11（64 位）
- 从 [最新 Release](../../releases/latest) 下载 `Knownest-Setup-<版本>.exe`，双击安装
- 按用户安装，无需管理员权限；应用内置自动更新（差量下载），后续版本无需手动升级

### 🍎 macOS（Apple Silicon）

- 系统要求：macOS 10.15 及以上（M1 / M2 / M3 / M4）
- 状态：开发中，即将提供——届时从同一 [Releases 页面](../../releases/latest) 下载 `.dmg`

> Release 资产里的 `latest.yml`、`*.blockmap`、`*.zip` 是应用自动更新组件，无需手动下载。
