**Knownest** is a local-first AI knowledge management desktop app: organize, edit, connect and review your Markdown notes in one place, with a built-in autonomous AI agent operating your knowledge base. All data stays in local SQLite and Git. Open source under MIT.

- Website: https://knownest.io
- Privacy / Refund / Contact: https://knownest.io/policies.html

## Download

### 🪟 Windows

- Requirements: Windows 10 / 11 (64-bit)
- Download `Knownest-Setup-<version>.exe` from the [latest release](../../releases/latest) and run it
- Per-user install, no admin rights needed; the app updates itself (delta downloads) — no manual upgrades required

### 🍎 macOS (Apple Silicon)

- Requirements: macOS 10.15+ (M1 / M2 / M3 / M4)
- Status: in development, coming soon — the `.dmg` will be available on the same [Releases page](../../releases/latest)

> Files like `latest.yml`, `*.blockmap` and `*.zip` in a release are auto-update components — no need to download them manually.
